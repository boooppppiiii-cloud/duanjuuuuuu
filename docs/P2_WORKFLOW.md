# P2 运营工作台说明

## 产品定位

本应用把短剧社媒运营中分散的剧目素材、账号矩阵、生产任务、发布记录、数据回收和评论舆情集中到同一条工作流中。默认优先采用本地文件、规则和可导入表格；只有文案/封面生成、评论深度研判等明确需要智能能力的步骤才调用模型。

## 工作流

1. **数据中台**：汇总近 7 天矩阵表现、发布进度、待处理舆情和风险提醒，可导出 CSV。
2. **账号矩阵 / 剧库**：账号状态、平台、类型和发布记录统一维护；剧目仍以本地目录为主数据源。
3. **内容加工**：切片、字幕、竖屏规格化、敏感内容检测、标题文案和封面生产。
4. **分发互动**：普通社媒使用多内容 × 多账号批量排期；Meta 长剧集使用独立的 SFS 官方投递流程。
5. **舆情中心**：支持 CSV/JSON 本地导入与已连接平台同步；默认用本地规则分析，只有主动选择“AI 深度分析”才使用模型。平台回复必须再次确认并由官方接口提交。

## Meta SFS 一键构建

“Meta 投递”页执行两步：先预检，再生成包。系统会自动：

- 将剧集按 `<series>_ep001_<total>.mp4` 形式连续编号；
- 统一转为 1080×1920、H.264、3Mbps、AAC 双声道；
- 从剧照生成 1440×1920 竖版封面和 1200×1200 方形封面；
- 生成带 UTF-8 BOM 的系列 CSV、可选剧集 CSV、校验报告与投递说明；
- 对无法安全自动修复的问题（如单集不足 60 秒、超过 3 分钟、文件超过 2GB）阻止构建。

构建完成后，可由应用通过 Google Drive 服务账号自动上传整个文件夹，并至少以 Viewer 权限共享给 `sfs-viewer-drive-reader@sfs-content-viewer.iam.gserviceaccount.com`；随后使用已获准的 Instagram 账号打开 `https://www.instagram.com/sfs_tools` 提交文件夹链接。该流程不是 Graph API 静默上传。

## 可选环境变量

- `GEMINI_API_KEY` / `QWEN_API_KEY`：智能生成与评论深度分析；不配置时明确提示，普通本地规则分析仍可使用。
- `CREDENTIAL_SECRET`：在应用内加密保存平台凭证时必填；也可仅保存环境变量名。
- `PUBLIC_API_ORIGIN` / `PUBLIC_UI_ORIGIN`：OAuth 回调与公开媒体地址使用的应用地址。
- `GOOGLE_DRIVE_SERVICE_ACCOUNT_FILE` / `GOOGLE_DRIVE_PARENT_FOLDER_ID`：Meta SFS 投递包一键上传所需配置。

普通发布只调用已连接账号的官方接口。缺少凭证、平台拒绝或处理失败都会显示为阻塞/失败，不会生成本地假成功记录。

所有密钥均由使用者最后写入 `.env`，不应提交到版本库。
